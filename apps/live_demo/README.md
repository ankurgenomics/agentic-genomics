# GenomicsCopilot — live demo

Deployed on Streamlit Community Cloud from this repo. Main file path:
`apps/live_demo/app.py`.

Live variant interpretation: VCF + phenotype (HPO terms) in, ranked
evidence-grounded ACMG-lite calls out — querying real MyVariant.info
(gnomAD/ClinVar/CADD) and JAX HPO data on every run. No API key required
for this deployment; see the "About the full agent" tab for what's
intentionally left out of the public demo and how to run it locally.

Research demonstration only — not a medical device, not for clinical use.

Source: [github.com/ankurgenomics/agentic-genomics](https://github.com/ankurgenomics/agentic-genomics)
